## விதி வரியின் இலக்கணம்

விதி வரி முழுவதற்கும் (இடப்பக்க வடிவம், புணர்ச்சிவகை, வலப்பக்க மாற்றங்கள்) முறையான இலக்கணம்
`pytamil/தமிழ்/resources/புணர்ச்சிவிதிகள்.g4` (ANTLR). விதி ஏற்றப்படும்போது ஒருமுறை பாகுபடுத்தி
`புணர்ச்சி.புணர்ச்சிவிதி` பொருளாக்கப்படும்; இலக்கணத்திற்கு அமையாத வரி `புணர்ச்சிவிதிப்பிழை` எழுப்பும்.

    (...)(இ,ஈ,ஐ) + (உயிர்)(...) = நிலைமொழி|உடம்படுமெய்(ய்) + வருமொழி
    (...)('ண்') +வேற்றுமை+ (வல்லினம்)(...) = நிலைமொழி|திரிதல்('ட்').வருமொழி

வடிகட்டிகள்: உடம்படுமெய்(எழுத்து), இரட்டுதல், திரிதல்(எழுத்து), சும்மா. இணைப்பு `+` = விளைவின் மேல்
விதிகளை மீண்டும் செயற்படுத்து; `+இயல்பு+` அல்லது `.` = இயல்பாகச் சேர்.
